# cpp-algorithm-templates

C++ 算法竞赛模板库

主要备战常见编程竞赛，
每一份模板都是亲手写过、编译通过、用题目验证过的。

## 收录规则

- **亲手写过**：必须自己敲过一遍
- **编译通过**：`-Wall` 零警告
- **题目验证**：在题目上跑通过
- **最小可用**：只保留比赛时真正会用的写法
- **注明信息**：每个模板文件头部注明适用场景、时间复杂度、易错点
- **题面与样例**：每个模板文件头部包含对应题目（描述、输入格式、输出格式）与至少 2 组测试样例（输入/输出），样例均经实测核对无误；提交时按专题拆分，一个专题的改动单独提交，不混杂其他专题
