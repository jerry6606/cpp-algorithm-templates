# cpp-algorithm-templates

C++ 算法竞赛模板库：自己攒的。

主要备战蓝桥杯，
每一份模板都是亲手写过、编译通过、用题目验证过的。

## 收录规则

- **亲手写过**：复制粘贴的不收，必须自己敲过一遍
- **编译通过**：`-Wall` 零警告是底线
- **题目验证**：至少在一道题上跑通过
- **最小可用**：只保留比赛时真正会用的写法，不堆花活
- **注明信息**：每个模板文件头部注明适用场景、时间复杂度、易错点
