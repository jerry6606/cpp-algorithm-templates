# 二分查找

已收录（每份 .cpp 文件头均含完整题目、输入输出格式与 2 组测试样例）：

- `lower_bound.cpp`：查找第一个 >= x 的位置（不存在输出 -1）。
- `upper_bound.cpp`：查找第一个 > x 的位置（不存在输出 -1）。
- `last_le.cpp`：查找最后一个 <= x 的位置（不存在输出 -1）。
- `range_count.cpp`：统计升序数组中落在 [L, R] 内的元素个数。
- `int_sqrt.cpp`：二分答案·整数平方根，最大的 m 使 m*m <= n（防溢出写法）。

说明：打开任意一份 .cpp，先看文件头的题目与样例确认输入输出顺序，再对照下方的模板说明（场景、复杂度、易错点）复习。

收录标准见仓库根目录 README：亲手写过、-Wall 零警告、题目验证过。
