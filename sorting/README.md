# 排序与分治

已收录（每份 .cpp 文件头均含完整题目、输入输出格式与 2 组测试样例）：

- `quick_sort.cpp`：快速排序，中点值划分后递归左右两段。
- `quick_select.cpp`：快速选择，只递归包含第 k 小数的一侧。
- `merge_sort.cpp`：归并排序，稳定，合并时使用分离双指针。
- `count_inversions.cpp`：归并排序统计逆序对，合并阶段用 `mid - i + 1` 批量结算。
- `struct_sort.cpp`：结构体多级排序，总分降序、语文降序、学号升序三级比较；学号按字符串处理（保留前导 0）。

说明：打开任意一份 .cpp，先看文件头的题目与样例确认输入输出顺序，再对照下方的模板说明（场景、复杂度、易错点）复习。

收录标准见仓库根目录 README：亲手写过、-Wall 零警告、题目验证过。
