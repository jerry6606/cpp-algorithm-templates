# 双指针

已收录（每份 .cpp 文件头均含完整题目、输入输出格式与 2 组测试样例）：

- `is_subsequence.cpp`：分离双指针，判断一个字符串是否为另一个字符串的子序列（LeetCode 392 同型）。
- `longest_subarray_sum_at_most_k.cpp`：正数数组滑动窗口，求和不超过 k 的最长连续子数组（仅适用于正数数组）。
- `sorted_squares.cpp`：对撞双指针，有序数组平方后按升序输出（LeetCode 977 同型）。
- `remove_duplicates_sorted.cpp`：快慢双指针，原地删除升序数组中的重复项并输出去重后数组（LeetCode 26 同型）。
- `longest_non_repeating_subarray.cpp`：滑动窗口加 cnt 计数，最长连续不重复子序列（AcWing 799）。

说明：打开任意一份 .cpp，先看文件头的题目与样例确认输入输出顺序，再对照下方的模板说明（场景、复杂度、易错点）复习。

收录标准见仓库根目录 README：亲手写过、-Wall 零警告、题目验证过。
