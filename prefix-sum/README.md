# 前缀和与差分

已收录（每份 .cpp 文件头均含完整题目、输入输出格式与 2 组测试样例）：

- `prefix_sum.cpp`：一维前缀和（区间求和）。
- `prefix_sum_2d.cpp`：二维前缀和（子矩阵求和）。
- `prefix_xor.cpp`：一维前缀异或（区间异或）。
- `diff.cpp`：一维差分（区间加、还原输出）。
- `diff_2d.cpp`：二维差分（子矩阵加、还原输出）。

说明：打开任意一份 .cpp，先看文件头的题目与样例确认输入输出顺序，再对照下方的模板说明（场景、复杂度、易错点）复习。

收录标准见仓库根目录 README：亲手写过、-Wall 零警告、题目验证过。
