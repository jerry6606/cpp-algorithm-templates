# 高精度

已收录（每份 .cpp 文件头均含完整题目、输入输出格式与 2 组测试样例）：

- `add.cpp`：高精度加法，非负大整数逐位相加并处理进位。
- `subtract.cpp`：高精度减法，先比大小再逐位借位，结果可为负。
- `multiply.cpp`：高精度乘法，错位累加各位乘积后统一进位。
- `divide.cpp`：高精度除法，逐位试商，输出商和余数共两行（除数不能为 0）。

说明：打开任意一份 .cpp，先看文件头的题目与样例确认输入输出顺序，再对照下方的模板说明（场景、复杂度、易错点）复习。

收录标准见仓库根目录 README：亲手写过、-Wall 零警告、题目验证过。
